# Calculadora Científica em Python

Projeto desenvolvido para praticar programação em Python.

## Funcionalidades

 Operações matemáticas básicas
Potenciação e divisão inteira
 Raiz quadrada
 Funções trigonométricas
 Logaritmos
 Constantes matemáticas Pi e E
 Histórico de cálculos

## Tecnologias utilizadas

 Python
 Biblioteca AST
 Biblioteca Math
Biblioteca Operator

## Como executar

1. Tenha o Python instalado.
2. Baixe o arquivo calculadora_cientifica.py.
3. Execute no terminal:

python calculadora_cientifica.py
